Features

Engineered for Perfection

Every detail is carefully crafted to deliver the lightest, most polished Nepali date experience on Windows.

Ultra-Efficient Resource Usage

Engineered from the ground up to consume essentially 0.00% CPU and a tiny RAM footprint. Instead of constantly running conversion algorithms, the widget uses an intelligent caching technique — it only recalculates once per day at midnight. For the other 86,399 seconds, it paints cached text with zero math overhead.

Architecture

How It Works

Pure native Win32 API — no Electron, no .NET, no browser engine. Just raw, efficient C++ talking directly to Windows.

01

Ask Windows for the Date

Every second, the widget makes a nearly zero-cost system call to get the current Gregorian date from the OS.

02

Check if the Day Changed

A simple integer comparison — has the day/month/year changed since the last frame? This costs virtually nothing.

03

Convert Once Per Day

Only at midnight does the widget perform the Bikram Sambat conversion and re-render. The BS calendar (2032–2157 BS) is fully embedded in the binary.

04

Paint Cached Text

For the remaining 86,399 seconds of the day, it simply paints the cached text with GDI+ per-pixel alpha blending. Zero math, zero overhead.
